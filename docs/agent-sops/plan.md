# Plan mode SOP

| Field | Guidance |
|-------|----------|
| **Purpose** | Research, synthesize implementation plan — **no file writes** |
| **Allowed** | Readonly tools; parallel readonly discovery subagents |
| **Default workflows** | Cross-workspace pattern extraction; wave breakdown; ownership tables |
| **Context budget** | Parent ~85%; spawn readonly subagents for wide scans at 70–90% |
| **Handoffs** | Approved plan + todos → **Agent** for execution; open product decisions → user |
| **Invoke** | User selects Plan mode; “prepare plan before building” |
| **Anti-patterns** | Writing scaffold files during plan; skipping disjoint ownership table; plans without test/review gates |
